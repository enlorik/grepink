# Notebook studio redesign

Direction: Apple Notes' quiet document hierarchy, adaptable sidebar and bounded
inspector, with a restrained rose accent. Craft block editing and Obsidian Live
Preview inform passage editing. No copied brand assets or embedded Apple fonts.

- [x] Diagnose first-source loss, broken emphasis, popup overlap and raw editor.
- [x] Research Apple layout, sidebars, inspectors; Craft and Obsidian editing.
- [x] Neutral surfaces, charcoal typography and restrained rose controls.
- [x] Preserve every inline citation and avoid manufacturing list markers.
- [x] Avoid splitting claims inside bold text or code.
- [x] Render and edit individual passages, preserving neighboring Markdown.
- [x] Dock source inspection inside the note and embedded answer layouts.
- [x] Route wheel gestures over cited passages to the active excerpt.
- [ ] Regression tests and formatter/analyzer verification.
- [ ] Inspect rendered desktop and compact layouts.
- [ ] Publish tested Windows preview in GitHub Releases.

Source excerpts remain saved excerpts, never a claim to reproduce a live website.
Existing notes are not silently rewritten. Explicit Save persists passage edits.
